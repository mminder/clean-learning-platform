# Clean Learning Platform

A web platform where customers buy and book consultations and training courses, experts deliver them, and admins manage the offerings. It's being built as a PoC first, then refined into an MVP.

**Status:** the first increment, [01 Shop tracer bullet](_docs/specs/01-shop-tracer-bullet.md), is in progress. The shop list works end to end: the seeded Career Coaching offering goes from Postgres through the Spring Boot API to a card in the React shop.
